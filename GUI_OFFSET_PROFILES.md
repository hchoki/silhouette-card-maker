# GUI Offset Profiles Guide

## What's New?

The GUI's **Offset PDF** tab now includes full support for **Offset Profiles**, allowing you to save and manage multiple printer/paper size configurations easily!

## Features

### 📋 Profile Management
- **Save Multiple Profiles**: Create named profiles for different printers or paper sizes
- **Quick Loading**: Select a profile from the dropdown to instantly apply its settings
- **Default Profile**: Set a default profile that loads automatically
- **Profile Information**: See description, paper size, and offset values at a glance

### How to Use

#### Creating a New Profile
1. Navigate to the **Offset PDF** tab
2. Adjust your **X Offset** and **Y Offset** values to match your printer
3. In the **"Save New Profile"** section:
   - Enter a **Profile Name** (e.g., "HP LaserJet Letter")
   - Add a **Description** (e.g., "Home printer with letter paper")
   - Select the **Paper Size**
4. Click **"💾 Save Current Settings as Profile"**

#### Loading a Profile
1. Select a profile from the **dropdown menu** at the top
2. The offset values will automatically update
3. Click **"⚙️ Apply Offset"** to process your PDF

#### Setting a Default Profile
1. Select the profile you want as default
2. Click **"Set as Default"**
3. This profile will load automatically when you open the GUI

#### Deleting a Profile
1. Select the profile you want to remove
2. Click **"Delete"**
3. Confirm the deletion

### 💡 Profile Information Display
Below the profile dropdown, you'll see detailed information about the selected profile:
- Description
- Paper size
- X and Y offset values
- [DEFAULT] indicator if it's the default profile

### 🔄 Backwards Compatibility
The new profile system is fully compatible with the legacy offset system. Any existing offset configurations will continue to work.

## Example Workflow

1. **First-time setup**: 
   - Print a calibration PDF
   - Measure the offset
   - Save as a profile (e.g., "Canon Pixma A4")

2. **Daily use**:
   - Open the GUI
   - Your default profile loads automatically
   - Generate your PDF and apply offset with one click!

3. **Multiple printers**:
   - Save a profile for each printer
   - Switch between them using the dropdown
   - No need to remember offset values!

## Benefits

✅ **No more guessing**: Save your calibrated offsets once, use them forever  
✅ **Multiple setups**: Different profiles for different printers or paper sizes  
✅ **Quick switching**: Change configurations with a single click  
✅ **Organized**: Add descriptions to remember which printer each profile is for  
✅ **Set and forget**: Default profile loads automatically
